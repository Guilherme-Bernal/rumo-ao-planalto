# Rumo ao Planalto

Simulador de carreira política no navegador: comece como vereador e tente chegar à Presidência. Escolhas, eleições, coalizões, relações exteriores, guerras no mundo e leis.

**Jogar:** https://guilherme-bernal.github.io/rumo-ao-planalto/

> Obra de ficção e paródia. Não tem vínculo com partidos, candidatos ou pessoas reais. O progresso fica salvo só no seu navegador (localStorage).

## Rodar localmente

    npm install
    npm run dev

## Apoie

Curtiu o jogo? Use o botão "Apoie" dentro do jogo para ajudar a manter e evoluir o projeto.
